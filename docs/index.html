Deterministic Quality Assurance

The 5 Quality Gates Specification

Transparent, evidence-based engineering breakdown of what each gate validates, its limitations, file targets, and corresponding test suites.

1. WCAG 2.2 Contrast

gate_contrast_wcag.py

Calculates relative luminance \(L = 0.2126R + 0.7152G + 0.0722B\) to enforce 4.5:1 for body copy and 3.0:1 for graphical interfaces.

Checks: Exact hex, RGB, CSS token contrast in light & dark themes.
Does NOT Check: Text placed over dynamic canvas or bitmap images.
Test Suite: tests/test_contrast.py (12 tests)

2. True BiDi & Logical

gate_bidi_logical.py

AST regex and parser enforcing 100% CSS logical properties. Zero tolerance for physical coordinates.

Checks: Disallows physical margins, physical coordinates, and physical float.
Enforces: margin-inline, inset-inline, padding-inline.
Test Suite: tests/test_bidi.py (10 tests)

3. FSM Integrity

gate_fsm_integrity.py

Validates deterministic state transition graphs, BFS reachability from initial state, and race locks.

Checks: Double-click locks during async states, error recovery paths.
Enforces: allowClick: false during submitting/loading.
Test Suite: tests/test_fsm.py (11 tests)

4. DOM & Layout Shift

gate_cwv_budget.mjs

WHATWG-compliant parse5 iterative stack traversal enforcing max DOM depth ≤ 32 and media dimension reservations.

Checks: Positive integer width/height attributes, valid aspect-ratio syntax.
Safety: Stack overflow protected with visit limits on adversarial input.
Test Suite: tests/test_cwv.py (26 tests)

5. Anti-Slop Inspector

gate_no_slop.py

Detects and flags generic AI cliches: uncalibrated indigo gradients, raw emoji icons in buttons, and hardcoded values.

Checks: Rejects #6366f1 gradients, requires SVG icons.
Enforces: Semantic design tokens and professional visual hierarchy.
Test Suite: tests/test_slop.py (8 tests)

Developer Tooling & CLI

Installation & CLI Usage

Orthotect provides zero-config command line tools to scaffold, compile, and verify projects deterministically in local environments and GitHub Actions CI.

1. Installation

Install globally via npm or run on-demand using npx:

npm install -g orthotect
npx orthotect --version

2. Project Scaffolding

Initialize tokens, FSM specifications, and AGENTS.md in a repository:

orthotect init ./my-project
orthotect init .

3. Token Compilation

Compile 3-tier DTCG JSON into light & dark CSS custom properties:

orthotect compile core/tokens --out dist/tokens.css

4. Quality Gate Verification

Execute all 5 gates with parallel execution and zero-fallback boundaries:

orthotect verify ./src
orthotect verify . --json
orthotect verify . --md

GitHub Actions CI Integration

Drop this step into your .github/workflows/ci.yml pipeline to fail builds deterministically:

- name: Run Orthotect Quality Gates
  run: |
    npx orthotect verify ./src --json > orthotect-report.json
    npx orthotect verify ./src
