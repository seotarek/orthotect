ENGINEERING CONSTITUTION

The 7 Non-Negotiable Laws of Interface Engineering

Every line of code produced by AI coding agents must pass these 7 foundational laws before merging.

LAW 1 Law of Mathematical Contrast
WCAG 2.2 AAA (7.0:1) & AA (4.5:1)

Contrast is a mathematical formula of relative luminance, never subjective aesthetic opinion. Low-contrast muted text is strictly rejected.

/* VIOLATION: Contrast 2.3:1 (REJECTED) */
color: #4b5563;
background-color: #0d1117;
/* CERTIFIED: Contrast 17.1:1 AAA (PASS) */
color: var(--ot-content-primary); /* #f8fafc */
background-color: var(--ot-surface-canvas);
LAW 2 Law of Directional Neutrality
100% CSS Logical Properties

Physical coordinates (left, right, margin-left, padding-right) fail build gates. Use directional-neutral logical properties for seamless LTR/RTL symmetry.

/* VIOLATION: Banned Physical Coordinates */
/* Banned: margin-left, padding-right, text-align: left */
physical-coord: left-offset(1rem);
side-spacing: right-edge(0.75rem);
/* CERTIFIED: True Bidirectional Symmetry */
margin-inline-start: 1rem;
padding-inline-end: 0.75rem;
text-align: start;
LAW 3 Law of State Closure
Finite State Machines (FSM)

Component behavior must be modeled as a closed Finite State Machine. Loose boolean flags (isLoading, isError) that allow invalid state combinations are banned.

// VIOLATION: State explosion bug
const [isLoading, setIsLoading] = useState(false);
const [isError, setIsError] = useState(false);
// Race bug: isLoading && isError simultaneously!
// CERTIFIED: Formal Closed FSM State
type State = 'idle' | 'loading' | 'success' | 'error';
// Async edges locked; double-clicks impossible
LAW 4 Law of Zero Cumulative Layout Shift
CLS = 0.00 & Media Bounds

Every image, video, SVG, and iframe must declare explicit positive integer width and height attributes or valid CSS aspect-ratio before layout computation.

<!-- VIOLATION: Unbounded Media (CLS Spike) -->
<img src="hero.webp" alt="Hero" class="responsive" />
<!-- CERTIFIED: Guaranteed Zero Layout Shift -->
<img src="hero.webp" width="800" height="450" alt="Hero" />
LAW 5 Law of Cognitive Ergonomics
High-Density Telemetry

Telemetry and data displays must present maximum semantic clarity with zero visual clutter. Use inline SVG sparklines and gauges instead of bloated chart runtimes.

<!-- VIOLATION: 500KB heavy chart dependency -->
<div id="heavy-d3-chart-container"></div>
<!-- CERTIFIED: 2KB inline SVG sparkline -->
<svg viewBox="0 0 120 28" class="sparkline-svg">...</svg>
LAW 6 Law of Token Purity
W3C DTCG Token Bindings

Zero hardcoded hex, rgb, or pixel spacing in component stylesheets and markup. All colors, spacing, and radii must resolve through semantic DTCG tokens.

/* VIOLATION: Raw Hex Color Bypass */
color: #ef4444;
border: 1px solid rgba(239, 68, 68, 0.3);
/* CERTIFIED: Pure Semantic Token Resolution */
color: var(--ot-action-danger);
border: 1px solid var(--ot-border-subtle);
LAW 7 Law of Anti-Slop Discipline
Zero Generic AI Patterns

Bans statistical AI slop: multi-stop generic purple/indigo gradients, unstyled emoji icons inside interactive elements, and unvalidated card nesting.

<!-- VIOLATION: Generic AI Slop Gradient & Raw Emojis -->
<button class="banned-purple-gradient-btn">
  Launch Platform [Emoji Icon]
</button>
<!-- CERTIFIED: Architectural Design System -->

  <svg class="btn-icon" viewBox="0 0 24 24">...</svg>
